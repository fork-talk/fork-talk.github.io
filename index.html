Principles

Evidence first
Every claim links to data. Simulations, chain analysis, on-chain metrics. If it can't be measured, it doesn't belong here.
Pro-Bitcoin
This is a Bitcoin project. We care about the network's health, security, and function as peer-to-peer electronic cash.
Neutral on proposals
We present what proposals do, how they work, and what the data shows. We strip away bias and gaslighting - from any direction.
Open source
Everything is MIT licensed, hosted on GitHub Pages, no build steps. Fork it, fix it, improve it.
